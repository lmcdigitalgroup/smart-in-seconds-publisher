Smart in Seconds Publisher

Smart in Seconds Publisher es una aplicación privada de escritorio para Windows. Su propósito es ayudar al propietario del canal SmartinSecondsMedia a preparar metadatos, organizar una cola de publicaciones, verificar el canal autorizado y cargar videos mediante OAuth 2.0 de Google y YouTube Data API.

La aplicación funciona localmente, requiere revisión humana antes de cada publicación y no acepta registros ni acceso de terceros.

Política de privacidad Términos del servicio

Propósito de la aplicación

Administración autorizada de contenido

Smart in Seconds Publisher administra únicamente el canal de YouTube autorizado por su propietario.

  • Autorización mediante OAuth 2.0.
  • Verificación del canal autorizado.
  • Carga de videos y metadatos.
  • Revisión humana antes de publicar.
  • Datos almacenados localmente.

Funcionalidad

Qué hace Smart in Seconds Publisher

La aplicación facilita un flujo de trabajo bilingüe en inglés y español para administrar contenido del canal SmartinSecondsMedia.

Preparación de contenido

Organiza archivos de video, títulos, descripciones, etiquetas e idiomas antes de la carga.

Cola de publicaciones

Conserva fechas, horarios, estados y resultados de las publicaciones programadas.

Autorización con Google

Utiliza OAuth 2.0 para obtener autorización sin solicitar ni almacenar la contraseña de Google.

Integración con YouTube Data API

Utiliza los métodos channels.list y videos.insert para verificar el canal y cargar videos autorizados.

Revisión humana

Permite comprobar el video y sus metadatos antes de ejecutar una publicación.

Prevención de duplicados

Guarda identificadores y comprobantes técnicos para evitar cargas repetidas.

Registros técnicos

Conserva localmente estados, identificadores, fechas y errores necesarios para administrar el sistema.

Uso interno y privado

No se distribuye como servicio público, no ofrece cuentas a terceros y solo administra el canal autorizado.

Datos y privacidad

Uso limitado de los datos

Los datos obtenidos mediante Google y YouTube se utilizan exclusivamente para identificar el canal autorizado, cargar contenido, administrar metadatos y registrar el resultado de las operaciones.

Smart in Seconds Publisher no vende información, no crea perfiles publicitarios y no comparte datos con corredores de información.

Consulta la Política de privacidad de Smart in Seconds Publisher para conocer los datos utilizados, su conservación, eliminación y el procedimiento para revocar el acceso.

Control del propietario

  • Revisar los permisos concedidos.
  • Revocar el acceso desde la Cuenta de Google.
  • Solicitar la eliminación de datos locales.
  • Desactivar la automatización.
  • Revisar cada publicación antes de ejecutarla.
